# Goals

The intent of this application is to build a useful and fun spaceship editor,
but also an open source demo application showcasing the WebMCP APIs. It will be
deployed live as a single instance, but we hope that other developers will fork
the repo and play with it themselves. Optimize workflows and README content with
the assumption that many developers will fork and use this project themselves.

## General guidelines

- When authoring prose, use
  [Simplified Technical English](https://en.wikipedia.org/wiki/Simplified_Technical_English)
- Do not use emdashes in written content
- Do not include code comments that are related to the current request from the
  user - only include code comments that helpfully describe the code in question
  for human readers

## Design guidelines

- When creating web designs, avoid unnecessary placeholder copy and subtitles
- Do not use eyebrow headings unless explicitly instructed to do so
